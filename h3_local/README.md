# 本地 H3 提示词

重启 ComfyUI 后搜索 `本地H3提示词@炮老师的小课堂`。

也可导入插件 `examples/h3_local_prompt.json`：加载器 → H3提示词 → 文本预览。示例选用本机已有的 Qwen3.5-4B 及其 mmproj；分享后按接收方实际模型调整下拉选项。

## 接线与模型

1. 添加已有的 `🤖大炮本地模型加载器@炮老师的小课堂`，选主模型及匹配的 mmproj，将「本地模型」输出接到新节点。
2. 模型仍从插件已有的 `ComfyUI/models/LLM` 下拉列表选择，不必新建 `Qwen3.8` 子目录，也不下载模型。
3. 思考开关、Qwen3.8 推理强度、上下文长度、GPU 层数和 KV 缓存均在加载器设置。可先关闭思考，上下文设 32768；多图、多视频或较长 Skill 可能需要更长上下文及更多显存。
4. 填写需求，Skill 选 `auto` 或指定 Skill。「H3提示词」输出接原工作流需要提示词的位置；其余两项输出是 Skill ID 和模式 ID。
5. 参考图每个接口一张；参考视频接口接 IMAGE 帧批次，读取视频时设为 24fps。连接接口后会自动增加下一接口。与原节点一样，视频以每秒采样拼图理解，不读取音轨。

纯文字可以不选 mmproj；图片和视频必须有匹配的视觉投影。原节点的 9 套内置 Skill、多图/视频、自动模式识别（t2va/i2va/l2va/fl2va/ref2va）、自动 Skill 选择、随机种子和空输出重试均已接入。默认完成后卸载模型；如果加载器打开「推理后卸载模型」，同样会卸载。推理报错后也会清理。

原有工作流需要手动换成新节点并重新接线；旧的 `QwenH3PromptLocal` 不会被替换。原插件可以保留，两者互不覆盖。生成文本遵循原版 Skill 的格式和语言要求，换模型后质量、措辞与原节点不保证相同。

## 分享整合包

本功能使用整合包的 `llama-cpp-python`，不启动 llama-server，不需要运行原插件的 `install_runtime.py`，也不读取其 `runtime_config.json`。连同本插件、便携 Python、依赖 DLL 和模型一起打包即可携带这部分功能。插件内提示词资料按自身位置定位；模型沿用原加载器目录规则。接收方仍需要与整合包兼容的系统、显卡驱动和足够内存/显存；其他插件或启动器中的绝对路径需另行检查。

自定义 H3 Skill 放在 `h3_local/custom_skills/<skill-id>/SKILL.md`，重启后出现在列表。这里只把 Skill 当作模型提示词，不执行其中的脚本或工具。本目录与插件原有多轮对话的 Skill 管理分别存放，避免覆盖用户资料。
